# 全 Java 低性能 Android TV 播放器 —— 实现方案

原型：`preview/proto.html`（浏览器打开，方向键操作，按 E 出设置页，Esc 收起面板）

## 一、这套 UI 难不难？——拆开看，一点都不难

这界面看着高级，**没有一处用到了复杂技术**。全部是：

| 元素 | 技术实现 | 难度 |
|---|---|---|
| 半透明面板 + 渐变遮罩 | 一个 `LinearGradient` + `canvas.drawRect` | 5 分钟 |
| 卡片圆角 + 焦点描边 | `Paint.setStyle(STROKE)` + `drawRoundRect` | 5 分钟 |
| 焦点放大 / 变色 | `animate().scaleX/Y()` + `ArgbEvaluator` | 10 分钟 |
| 竖排「节目 » 信息」 | `TextView.setRotation(90)` 或逐字竖排 | 10 分钟 |
| 频道滚动 + 焦点保持可见 | `ViewCompat.animate().translationY()` 一次计算 | 30 分钟 |
| 设置页行 + 分段选择器 | 一个 `RowView`（自绘）+ 一个 `SegmentedView`（自绘） | 1 小时 |

**真正花时间的是三件事，跟 UI 无关：**
1. 焦点引擎（跨栏跳转、边界处理、返回键层级）—— 约 400 行 Java
2. 播放器封装（切台不黑屏、断流重连、软解兜底）—— 约 600 行 Java
3. 数据层（频道源解析、EPG 对齐、缓存）—— 约 500 行 Java

## 三、低性能设备的关键约束（照着写就不会卡）

1. **不引 Leanback**（省 800KB + 免掉它的 `Presenter` 层层封装），焦点自己算。
2. **不引 Material Components**（`MaterialCardView` 每次焦点变化会建离屏 layer，低端 GPU 上直接掉至 20fps）。所有卡片自绘。
3. **不做模糊**。`RenderEffect` / `RenderScript` / `BlurMaskFilter` 在低端盒子上都是灾难，用半透明纯色 + 渐变代替。
4. **所有 Paint / RectF / Path 设为成员变量**，`onDraw` 里零分配。
5. **字符串拼接提前算**，`onDraw` 里不 `String.format`。
6. **动画只用 `ViewPropertyAnimator`**（硬件加速走 RenderThread），不要 `ValueAnimator` + 手动 invalidate。
7. **列表不用 RecyclerView 的 ItemAnimator**，`setItemAnimator(null)`；频道数 <200 时甚至可以直接用 `LinearLayout` + 复用 View 池（低端机上比 RecyclerView 更快，因为省掉 Recycler 的滚动计算）。
8. **播放器与 UI 同进程可以，但切台必须“先停后起 + 保留 SurfaceView”**。低端机同时跑两个解码器会 OOM/黑屏。
9. **台标图统一 96×96 解码**（`inSampleSize` 算好），不要原图直入。463 个频道全加载原图必 OOM。
10. **minSdk 21（Android 5.0）**，TV 盒子覆盖最广；`targetSdk 34`。

## 四、焦点引擎（这是全项目最容易写错的地方）

不用 `android:nextFocusDown` 那套 XML 硬编码，写一个 400 行的引擎：

```java
public final class FocusEngine {
    // 4 个焦点区：NAV / CHAN / SETTINGS_ROW / SETTINGS_OPT
    private int zone = Zone.CHAN;
    private int navIndex = 1, chanIndex = 0, settingRow = 0, settingOpt = 0;

    public boolean dispatch(int keyCode) {
        switch (keyCode) {
            case KeyEvent.KEYCODE_DPAD_UP:
                if (zone == Zone.NAV)  navIndex = Math.max(0, navIndex - 1);
                else if (zone == Zone.CHAN) chanIndex = Math.max(0, chanIndex - 1);
                else if (zone == Zone.SETTINGS_ROW) { settingRow = Math.max(0, settingRow - 1); settingOpt = 0; }
                return true;
            case KeyEvent.KEYCODE_DPAD_LEFT:
                if (zone == Zone.CHAN) zone = Zone.NAV;
                else if (zone == Zone.SETTINGS_ROW) settingOpt = Math.max(0, settingOpt - 1);
                return true;
            // ... 对称实现
        }
        return false;
    }
    public void commit() { /* 一次性把焦点状态推给各 View，不逐帧计算 */ }
}
```

要点：
- **只在按键时计算一次**，不监听 `OnFocusChangeListener` 做联动（那会导致焦点事件风暴）。
- 列表在**值变化后**再做一次「焦点保持可见」的位移计算，用 `translationY` 而不是重新 layout。
- 跨栏（← 到导航、→ 到频道列）不做飞行动画，跟遥控器手感匹配的是**瞬时 + 焦点框 120ms 内放大**。

## 五、播放器封装关键代码结构

```java
public interface PlaybackBackend {
    void prepare(String url, boolean isLive);
    void start(); void pause(); void stop();
    void release();
    void setSurface(Surface s);
    void setListener(Callback cb);
    long getBufferedPosition();
}
```

- `Media3Backend`：`ExoPlayer.builder().setLoadControl(lowLatencyLoadControl())`
  - 直播低延迟：`DefaultLoadControl` 的 `bufferForPlaybackMs=500`、`bufferForPlaybackAfterRebufferMs=800`、`maxBufferMs=8000`
  - HLS 重连：`DefaultMediaSourceFactory` + `LoadErrorHandlingPolicy` 设 3 次重试，间隔 500/1000/2000ms
- 切台流程：`player.stop()` → `setMediaItem(newItem)` → `prepare()` → `play()`
  - **不要用 `player.seekTo` 切源**，低端机必卡 2 秒
- 断流检测：每 3 秒检查 `getBufferedPosition()` 是否前进，连续 2 次不动 → 自动重连（最多 5 次后弹「源失效，切换线路」）
- 软解兜底：`DefaultRenderersFactory.setExtensionRendererMode(EXTENSION_RENDERER_MODE_PREFER)`，花屏时降级

## 六、必须先跑一遍的性能基线

装上后在本机跑这 4 条，达不到就回头改：

| 检查项 | 达标线 |
|---|---|
| `adb shell dumpsys gfxinfo com.gg.tv` 里的 95th percentile | < 16ms（60fps） |
| 焦点移动 100 次后的 GC 次数 | 0 次 Full GC |
| 冷启动到首帧 | < 2.5s |
| 切台（同源不同频道） | < 1.2s |
| 常驻内存（含播放器） | < 180MB（1GB 机型的 18%） |

## 七、不建议做的事

- **别用 Compose**：全 Java 诉求下不适用，低端 TV 的 Compose 渲染性能也不如原生 View。
- **别引 Leanback**：省体积、省学习成本，你只有两栏 + 一个弹窗，自己算焦点更快。
- **别做「实时模糊遮罩」**：原型图里那层虚化其实是视频本身的画面，不是真的 blur；用 `alpha` 渐变就能骗过眼睛。
- **别把频道列表放 RecyclerView + DiffUtil**：463 条数据全量刷新时 DiffUtil 会卡 200ms，直接 `notifyDataSetChanged` + 固定高度。

## 八、设置页实现（照第二张图）

尺寸：宽 **1300**，居中，距顶 96，圆角 6，底色 `#232426`，外描边 `rgba(255,255,255,.10)`。

| 部件 | 参数 |
|---|---|
| 标题栏 | 高 76，底部 1px 分隔线；齿轮 30px 蓝色 `#3B82F6`；页签高 52 / 左右内边距 26 / 21sp；焦点页签白框（2px，outline-offset -2）；右侧 `v1.1.7` 20sp `#9A9A9E`；关闭 ✕ 44×44 |
| 行容器 | 左右内边距 24，行间距 12 |
| 设置行 | 最小高 82，圆角 4，底 `#2B2C2E`，左右内边距 18；焦点 = 2px 白描边（内缩） |
| 行标题 | 左区宽 340，主标题 23sp/600；副标题 16sp `#93939A`，上间距 5 |
| 分段选项 | 高 50，最小宽 86，圆角 4，间距 12，20sp；未选中 `#3A3B3E` / `#E6E6E8`；已选中 `#31543A` 底 + `#EAF7EE` 字 + 绿色 ✓ `#4ADE80`；焦点再加 2px 白框 |
| 底栏 | 高 62，顶部 1px 分隔线；蓝圆点 + 说明 17sp；右侧提示「按 OK(Enter) 键修改配置，按 ESC 返回主画面」 |

**注意**：只有当焦点落在**选项**上时才给选项白框；焦点落在**行**上时给整行白框、选项不着色。这就是原型里「白框 = 当前焦点」的意思。键盘流转：↑↓ 换行（焦点回该行已选值），←→ 在同一行的选项间移动，Enter 确认写入。

## 九、纯播放态（第一张图）

面板收起后只剩：**视频画面 + 右上角时钟 + 底部中央一条细指示条**。
- 面板隐藏动画：`alpha 1→0` + 频道列 `translationX 0→-40`，**240ms `DecelerateInterpolator`**
- 隐藏 5 秒后时钟也淡出（`alpha 1→0.35`，不是完全消失）
- 底部那根细条是页面指示器，TV 上一般不用，可去掉
- 任意方向键 / 返回键唤出面板，并恢复上次焦点
