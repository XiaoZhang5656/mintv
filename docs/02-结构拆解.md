# 原型按 1920×1080 做的精确拆解（可直接抄进 Java）

原型文件：`preview/proto.html`（浏览器打开，方向键可操作）

## 画面分区（单位 px，基准 1920×1080）

| 区域 | left | top | width | height | 说明 |
|---|---|---|---|---|---|
| 播放层 | 0 | 0 | 1920 | 1080 | SurfaceView，整屏铺满，永远在最底 |
| 左侧导航 | 0 | 0 | **300** | 1080 | 半透明渐变背景 + 右 1px 分隔线 |
| 频道列 | 301 | 0 | **476** | 1080 | 顶部 60px 标题条，下面滚动列表 |
| 节目信息轨 | 777 | 0 | **64** | 1080 | 竖排文字 + 左 1px 分隔线 |
| 右侧播放可见区 | 841 | 0 | 1079 | 1080 | 无遮罩，全透 |
| 遮罩（scrim） | 0 | 0 | **1180** | 1080 | 水平渐变，最右 40% 透明 |
| 时间块 | 右36 上30 | | | | 21px / 副行 18px |

合计：300 + 476 + 64 = 840，遮罩宽度 1180 > 840，多出的 340px 是“溢出淡出区”，避免列表边缘硬切。

## 各元素视觉参数

### 左导航
- 标题「频道列表」：29sp / 600 / letterSpacing 1px，图标 30px，间距 16px，下内边距 26px
- 分类项：高 **64**，圆角 **10**，左右内边距 16，图标 26，文字 23sp
- 计数胶囊：15sp 粗体，底色 `#8B8B6A`（暗金），文字 `#0B0B0C`，圆角 20，最小宽 38，内边距 2×9
- 当前分类（非焦点）：`rgba(255,255,255,.10)` 底
- 焦点态：底 `rgba(47,123,255,.16)` + **2px `#2F7BFF` 描边（内缩，outline-offset -2）** + scale 1.015；胶囊变色为 `#2F7BFF`/白字

### 频道项
- 高 **92**，外边距上下 7 左右 14，圆角 10，内边距左右 16
- 编号块 52×26，圆角 4，底 `rgba(255,255,255,.10)`，字 14sp `#B9B9BD`
- 主标题 24sp，letterSpacing .5；副行 15sp `#9A9A9E`，上间距 7
- 徽标：12sp，「播放中」蓝底白字，「可回看」灰底
- 常态底 `rgba(255,255,255,.05)`
- 焦点态：底 `rgba(47,123,255,.16)` + 2px 蓝描边 + 上抬 1.015（原型里没有 scale，正式版建议与导航一致）

### 节目信息轨
- 宽度 64，竖排 24sp letterSpacing 10，居中；「节目 » 信息」两段中间夹一个 18sp 的旋转 » 图标
- 竖排实现：单行 TextView + `setRotation(90)` 不换行，或 `LinearLayout` 每字一个 TextView。**低端机推荐 rotation 方案**，一个 View 就够。

### 时钟
- 两行右对齐：日期 21sp 白，星期时间 18sp `#CFCFCF`，都带 8px 黑色阴影（TV 上必须加，否则白底画面看不清）

### 遮罩
`linear-gradient(90deg, rgba(0,0,0,.94) 0%, rgba(0,0,0,.88) 52%, rgba(0,0,0,.55) 82%, transparent 100%)`
Java 里用 `LinearGradient(0,0,1180,0, new int[]{0xF0000000,0xE0000000,0x8C000000,0x00000000}, new float[]{0,.52f,.82f,1}, CLAMP)` 画一个 Rect。

## 交互行为（原型已实现，代码要一致）
1. ↑↓ 在当前栏内移动；←→ 在两栏之间切换；回车进入 / 播放；返回键或 Esc → **隐藏面板，只看视频**
2. 面板隐藏后，任意方向键 / 返回键 → 重新唤出，焦点回到上次位置
3. 切分类时频道列重置到顶部，焦点回第 0 项
4. 焦点滚动策略：只在焦点项超出可视区时滚动，**用 ViewCompat.animate().translationY()**，不要用 smoothScrollTo（低端机 300ms 内会掉帧）
5. 不用 RecyclerView 的 item 动画（`setItemAnimator(null)`）
