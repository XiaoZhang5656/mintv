# docs/ 说明

这个目录下三份文档是**项目早期（TVUI 阶段）的设计稿**，保留作为决策记录。

部分内容已经和现在的实现不一致，主要是：

| 文档里写的 | 现在的实现 |
|---|---|
| 播放用 Media3 ExoPlayer | **已删掉 Exo，改用 libVLC 单内核** |
| 双内核 + 降级链 | 单内核；为将来加内核留了 `PlaybackSession` 抽象 |
| 没有脚本能力 | QuickJS 脚本引擎已接入 |

不一致的原因：Exo 和 VLC 同时存在时，实例释放时序反复出问题
（切内核闪退、两个台同时出声、切主题黑屏有声）。这些问题的根因不是
"有两个内核"，而是缺少所有权边界 —— 最后选择删掉 Exo 收敛复杂度，
并把播放器所有权收进 `PlaybackSession`，为将来重新引入内核留好接口。

**当前架构和 API 请看仓库根目录的 [README.md](../README.md)。**

三份文档仍然有价值的部分：

- `01-技术选型.md` — 为什么不用 Leanback / Material Components，自绘 UI 的取舍
- `02-结构拆解.md` — 界面分区尺寸、焦点引擎设计
- `03-实现方案.md` — 数据层、EPG、缓存策略
